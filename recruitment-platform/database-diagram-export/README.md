# 📊 Job Recruitment Platform - Database Diagram & Schema Export

Thư mục này chứa toàn bộ sơ đồ cơ sở dữ liệu và tài liệu liên quan để chia sẻ cho các thành viên khác xem.

## 🚀 Các Tệp Trong Thư Mục:

1. ** / **:
   - Trang web xem sơ đồ ERD tương tác trực quan.
   - **Cách xem**: Nhấp đúp chuột vào file  để mở bằng bất kỳ trình duyệt web nào (Chrome, Safari, Edge...).
   - **Tính năng**:
     - Nhấp chọn từng bảng để xem các liên kết của bảng đó.
     - Bộ lọc xem theo từng Module (Người dùng, Việc làm, Phỏng vấn, Chat...).
     - Khung giải thích chi tiết mối quan hệ bên phải.

2. ****:
   - Mã nguồn định dạng Eraser.io. Có thể copy nội dung file này dán trực tiếp vào [Eraser.io](https://www.eraser.io/) nếu muốn chỉnh sửa trên cloud.

3. ****:
   - File cấu trúc cơ sở dữ liệu gốc (Prisma Schema).

4. ****:
   - Script Python dùng để tự động sinh lại file HTML sơ đồ khi có thay đổi trong .
